Консольное приложение на Java, симулирующее систему заказа еды на вынос.

ОПИСАНИЕ ПРОЕКТА

Проект разработан в рамках изучения продвинутых возможностей Java (Generics, Collections, Interfaces). Программа позволяет пользователю просматривать меню, выбирать блюда, следить за балансом своих средств и оформлять заказ.

ОСНОВНОЙ ФУНКЦИОНАЛ
- Просмотр меню с ценами и описанием блюд.
- Выбор блюда по его порядковому номеру.
- Автоматический подсчет итоговой стоимости корзины.
- Проверка достаточности средств на счету клиента.
- Безопасный ввод данных: обработка ошибок ввода через try-catch (программа не завершается аварийно при вводе букв вместо цифр).
- Оформление заказа со списанием средств и выводом финального чека.

ИСПОЛЬЗУЕМЫЕ ТЕХНОЛОГИИ И КОНЦЕПЦИИ
В ходе разработки были применены следующие концепции Java:
- ООП: Инкапсуляция (private поля), наследование и полиморфизм.
- Generics (Обобщения): Создание универсальных интерфейсов (PricedItem<T>) и классов (ShoppingBag<T>).
- Collections (Коллекции): Использование List (ArrayList) для хранения меню и Map (HashMap) для реализации корзины покупок.
- Interfaces (Интерфейсы): Создание контрактов для обработки пользовательского ввода (UserInputRetriever).
- Exception Handling: Обработка исключений IllegalArgumentException и InputMismatchException.
